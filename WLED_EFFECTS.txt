WLED 1D EFFECTS REFERENCE
=========================

This file describes the effects compiled into the esp32s3_4M_qspi firmware
that work on normal one-dimensional LED segments. Effects that require a 2D
matrix are intentionally excluded. It contains 161 built-in WLED effects and
the custom Numbered POV effect, ordered alphabetically by effect name.
Effects marked Audio use simulated audio unless a compatible audio source is
available.

NOTES
-----

- Effect IDs are retained for cross-reference but do not determine this file's
  alphabetical order.
- Numbered POV is the only custom effect in this firmware. It reads /1.bmp
  through /255.bmp and advances image columns using its 4-260 ms wait control.
- The Image effect reads supported image or animated GIF files from the WLED
  filesystem and is separate from Numbered POV.
- PS effects use WLED's particle-system engine and may require more memory or
  processing time than simpler effects.
- Effect availability and numeric IDs are specific to this firmware build.
